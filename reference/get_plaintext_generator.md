# The plaintext generator of an encoding

The generator of the cyclic group used to order the plaintext slots, as
recorded in an `EncodingParams` object.

## Usage

``` r
get_plaintext_generator(encoding_params)
```

## Arguments

- encoding_params:

  An `EncodingParams` object, from
  [`get_encoding_params()`](https://openfheorg.github.io/openfhe.R/reference/get_encoding_params.md).

## Value

A number.
