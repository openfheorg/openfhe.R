# CKKS Data Type

Mirrors the C++ enum `CKKSDataType` in `pke/constants-defs.h`.

## Usage

``` r
CKKSDataType
```

## Value

A named `list` of 2 integer scalars, each the value of the OpenFHE C++
enumerator of the same name, declaring whether the slots of a CKKS
ciphertext hold `REAL` or `COMPLEX` numbers.
